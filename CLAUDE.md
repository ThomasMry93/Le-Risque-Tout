# Le Risque Tout — notes pour Claude

- Tout le jeu tient dans `index.html` : styles, script et questions (constante `BUILTIN`, complétée par les thèmes perso dans `THEMES`). Pas de build.
- Interface et contenus en français. Le joueur ne touche pas le téléphone : un maître du jeu arbitre.
- Questions : chaque série a exactement 7 entrées `[question, réponse]` dans l'ordre x1, x2, x3, x4, x5, Risque Tout, Mega Risque Tout (Hardcore seulement), de la plus facile à la plus difficile. Les séries d'une même famille sont numérotées automatiquement (`Sport 1`, `Sport 2`…). Ajouter les nouvelles séries **à la fin** de `BUILTIN` : l'historique « déjà joué » repose sur ces noms.
- Thèmes perso : créés dans l'écran « Mes thèmes », stockés dans le `localStorage` du téléphone (clé `risque-tout-perso`) et ajoutés après `BUILTIN`. Le Mega Risque Tout y est facultatif. Chaque thème a un créateur (`author`).
- Partage des thèmes : collection commune sur un Cloudflare Worker (`cloudflare/worker.js`, stockage KV relié sous le nom `THEMES`, adresse dans `CLOUD_URL`). Partager demande la clé d'accès ; seules ses empreintes (`KEY_HASHES`, salées avec `KEY_SALT`) sont écrites dans le jeu et le Worker, jamais la clé. Les deux listes d'empreintes doivent rester identiques. Les thèmes récupérés portent `cloud: 1` et `cloudId` ; ceux supprimés sur le téléphone vont dans la liste `risque-tout-partages-supprimes`. Les thèmes perso supprimés vont dans une corbeille (`risque-tout-corbeille`, 100 au plus) d'où on peut les récupérer.
- Version démo : sans clé d'accès, seulement les 5 thèmes de `DEMO_THEMES` en mode Classique ; Hardcore, « Mes thèmes » et le réglage des valeurs sont verrouillés. Les clés d'accès (mêmes empreintes `KEY_HASHES`) débloquent le jeu complet : le téléphone garde `risque-tout-debloque` = "1" et la clé dans `risque-tout-cle`.
- Clés d'accès : la liste (clés du jeu, clés de Vingt Indices et codes de secours) est dans le Google Doc « Le Risque Tout – Clés d'accès », dossier « Risque Tout » du Drive de l'utilisateur. Après tout changement des empreintes dans `cloudflare/worker.js`, l'utilisateur doit recoller le fichier dans le Worker Cloudflare et déployer.
- Questions cadeau : constante `EASY`, tirées pour environ un thème sur cinq (`EASY_RATE`).
- À chaque mise à jour publiée : incrémenter `VERSION` dans `sw.js`, passer `APP_VERSION` au même numéro dans `index.html` et ajouter en tête de `CHANGELOG` les nouveautés, en phrases simples pour les joueurs (elles s'affichent dans le bandeau après la mise à jour).
- Mises à jour : le service worker télécharge la nouvelle version en arrière-plan mais ne l'installe que lorsque le joueur appuie sur « Mettre à jour » dans le bandeau.
- Façon de travailler : préparer et tester les changements dans Claude, et n'envoyer sur GitHub qu'après l'accord de l'utilisateur.
- Ne jamais toucher au dépôt Vingt-Indices depuis ce projet.
